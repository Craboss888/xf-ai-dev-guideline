# 必备装备清单（cc-preflight 第 3 步逐项过）

> 原则：**先检测 → 缺的装 → 逐项验证 → 如实汇报**。
> 安装命令以当下环境实测为准：动手前先跑 `claude plugin --help` 或查各项官方文档，**不凭记忆敲命令**。plugin / MCP 类装完通常要**重启会话**才生效——装完标 ⚠️ 说明即可，别谎报可用。
> 前提检查：Claude Code 已登录、有网络。

## 1. playwright（plugin · 浏览器自动化）

- **用途**：真实浏览器驱动——页面截图、点击验证、E2E 检查；前端「交付前自检」的主力工具。
- **检测**：会话内是否存在 `mcp__*playwright*` 工具；或 `claude plugin` 相关列表命令查已装 plugin。
- **安装指引**：Claude Code 官方 plugin 市场安装（以 `claude plugin --help` 输出的子命令为准）。
- **验证**：重启会话后 playwright 工具可调用（如 browser_navigate 一个页面）。

## 2. frontend-design（plugin · 前端设计）

- **用途**：生成有设计品味的前端界面，避免「AI 味」通用审美；配合用户的 UI 高标准偏好（丝滑、有质感）。
- **检测**：available skills 列表中有 `frontend-design`。
- **安装指引**：Claude Code 官方 plugin 市场安装（同上，以 `claude plugin --help` 为准）。
- **验证**：skill 列表可见；新会话可触发。

## 3. superpowers（第三方 skills 集 · 开发方法论）

- **用途**：brainstorming / TDD / systematic-debugging / verification-before-completion 等一组开发流程 skills。
- **检测**：`~/.claude/skills/` 下有对应 skill 目录，或 plugin 列表中可见。
- **安装指引**：GitHub `obra/superpowers` 官方 README 的安装方式（市场或 clone）。
- **验证**：skill 列表出现其子 skills（如 brainstorming）。

## 4. agent-reach（CLI + skill · 互联网调研路由器）

- **用途**：全网调研 / 平台内容获取（Exa 搜索、Twitter、Reddit、小红书、B 站、YouTube 等 13 平台多后端路由）。
- **检测**：`which agent-reach` + `agent-reach doctor --json`；`~/.claude/skills/agent-reach/` 存在。
- **安装指引**：GitHub `Panniantong/Agent-Reach` 官方安装文档（https://raw.githubusercontent.com/Panniantong/agent-reach/main/docs/install.md）；采用低风险基础安装，**不启用 `--channels=all`、不自动抽取浏览器 cookies**。
- **验证**：`agent-reach doctor --json` 返回各平台状态。

## 5. web-design-engineer（skill · 网页设计工作流）

- **用途**：6 步专业网页设计工作流，做完整 Web 交付物（落地页 / 仪表盘 / 原型）时用。
- **检测**：`~/.claude/skills/web-design-engineer/` 存在且含 SKILL.md。
- **安装指引**：GitHub `ConardLi/garden-skills` 仓库，取其中 web-design-engineer 目录放入 `~/.claude/skills/`；frontmatter 确认 `user-invocable: true`。
- **验证**：`/web-design-engineer` 出现在 skill 列表。
